SheetNester - portable package (Windows 10/11, 64-bit)
=====================================================
1. Unpack this zip to any folder, e.g. C:\SheetNester
   (avoid cyrillic letters and spaces in the path).
2. Run SheetNester.bat - the browser opens the app.
   Keep the console window open while working; closing it stops the app.
3. Optionally run "Create desktop shortcut.bat" once.
4. If Windows Firewall asks about python.exe - it can work only on this PC
   (the server listens on 127.0.0.1); you can block it safely.

Data (settings, warehouse) is created locally next to this file, nothing is
installed into the system. Internet is NOT needed on this PC.

Folder "DXF samples" - test parts (thickness and qty are read from file names,
e.g. "ME11 14mm 22pcs.dxf").
