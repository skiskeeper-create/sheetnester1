# SheetNester — расчёт себестоимости и нестинг DXF

## Запуск
Дважды щёлкнуть **Запуск.bat**. Откроется браузер с программой; окно консоли не закрывать, пока работаете
(закрыть окно = остановить программу).

- Нужен **Python 3.10+** (https://www.python.org/downloads/, при установке отметить «Add python.exe to PATH»).
- При первом запуске батник сам поставит пакеты `ezdxf` и `numpy` (нужен интернет один раз).
- Без Python батник откроет только калькулятор (вкладки «Расчёт», «Режимы», «Материалы», «Настройки», «Прайс»).
- Программа работает только на этом компьютере (адрес 127.0.0.1), в сеть ничего не отправляет.

## Перенос на другие ПК (для тестировщиков)
`python build_portable.py` (нужен интернет) собирает **SheetNester-portable.zip** рядом с собой. Внутри:
встраиваемый Python 3.12 с пакетами numpy/ezdxf, код приложения, примеры DXF, `SheetNester.bat`.
На целевом ПК: распаковать в папку без кириллицы/пробелов (например `C:\SheetNester`), запустить
`SheetNester.bat` (браузер откроется сам), один раз выполнить `Create desktop shortcut.bat`.
Python на целевом ПК не нужен, интернет не нужен. Склад и настройки создаются рядом с программой.

Версия показана под заголовком интерфейса; рассинхрон страницы и сервера подсвечивается предупреждением.

## Нестинг
1. Вкладка «Нестинг» → перетащить DXF (или «выберите файлы»). Толщина и количество берутся из имени
   файла («7-4057 16мм 2шт.dxf»), их можно поправить в таблице; там же выбирается материал.
2. Параметры: размер листа, отступ от края, зазор между деталями, шаг сетки, повороты, мосты, тип врезки.
3. «Разложить» → карты листов, КИМ, длина реза, проколы, время и себестоимость (по «Настройкам»,
   «Материалам» и «Режимам»); по каждой детали — себестоимость за штуку.
4. Для каждого листа сохраняется `.lxds` для CypCut Pro в папку `раскрой\<дата_время>`
   (или в указанную папку), кнопка «Открыть папку».

Детали одного материала и толщины раскладываются вместе; разные толщины — на разные листы.
Раскладка по реальному контуру: детали вкладываются друг в друга и в отверстия, повороты 0/90/180/270°.
Реальный зазор между деталями гарантированно не меньше заданного. Шаг сетки 2.5 мм — баланс точности и скорости
(меньше шаг — плотнее, но дольше).

## Состав
- `Расчёт себестоимости резки.html` — интерфейс (открывается и сам по себе, без нестинга).
- `server.py` — локальный сервер; `lxds/` — импорт DXF, нестинг, запись .lxds, тесты (`python test_*.py`).
- `data/template.lxds` — шаблон параметров CypCut (каналы реза и гравировки).

## Ограничения
- Параметры резки в .lxds подставляются по режимам из вкладки «Режимы» (мосты и врезки проверены в CypCut Pro 7.1).
- OCR по контурным текстам (PaddleOCR) в портативный пакет не входит — нужен только для текстов-кривых;
  текстовые надписи DXF (TEXT/MTEXT) гравируются без него (шаблон артикула — в «Настройках»).
- Нестинг: растровый, общего реза (common-line) нет; уплотнение произвольными углами ограничено точностью растра.
