Расчёт себестоимости лазерной резки

HSG G3050H, Raycus 3 кВт · данные хранятся в этом браузере · работает без интернета ·
Нестинг работает только при запуске через Запуск.bat (нужен Python). Сейчас файл открыт напрямую — доступен только калькулятор.
Перетащите DXF-файлы сюда или выберите файлы
Толщина и количество берутся из имени файла, например «7-4057 16мм 2шт.dxf»
Раскладка по реальному контуру: детали вкладываются друг в друга и в отверстия, повороты 0/90/180/270°. Стоимость — по формулам листа «Расчёт» с текущими «Настройками», «Материалами» и «Режимами», но длина реза и проколы — по реальным контурам (проколов на контур = число мостов, минимум 1), вес — по площади детали без отверстий. Для каждого листа сохраняется файл .lxds для CypCut Pro (параметры резки в CypCut выставляются по его библиотеке).
Как в листе «Расчёт»: вес и длина реза — по габаритам (прямоугольник), проколов на деталь = 1 + отверстия. Время, мин = длина реза / скорость + проколы × время прокола / 60. Стоим. материала = вес × цена кг / КПД раскроя.
Станко-час = БАЗА + Потребление × Тариф + Воздух × Цена воздуха + O2 × Цена O2 + N2 × Цена N2. Режим для детали подбирается по паре «материал + толщина».
Список толщин для детали берётся из листа «Режимы» по выбранному материалу.
