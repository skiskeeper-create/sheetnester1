# SheetNester — проделанная работа и что осталось (03.10.2026, версия 2026-10-03.2)

## Что это
Программа для лазерного станка HSG G3050H (Raycus 3 кВт, CypCut Pro 7.1): импорт деталей из DXF →
раскладка (нестинг) по реальному контуру → мосты и точки врезки → расчёт времени и себестоимости резки →
файл `.lxds` для CypCut + виртуальный склад листов и остатков. Работает локально (127.0.0.1), без интернета.

## Состав папки
| Файл | Что это |
|---|---|
| `SheetNester-portable.zip` | Установщик: портабельный пакет (~30 МБ), Python внутри, на целевом ПК ничего не ставится |
| `ТЗ.md` | Техническое задание v1.7 |
| `Проделано и планы.md` | Этот файл |

## Как установить (для тестировщика)
1. Распаковать zip в папку **без кириллицы и пробелов**, например `C:\SheetNester`.
2. Запустить `SheetNester.bat` — откроется браузер с программой. Окно консоли не закрывать,
   пока работаете (закрытие окна = остановка программы).
3. Один раз запустить `Create desktop shortcut.bat` — появится ярлык на рабочем столе.
4. Если брандмауэр Windows спросит про python.exe — можно запретить: программа работает только
   на этом компьютере.
5. Внутри пакета папка «DXF samples» — примеры деталей для проверки (толщина и количество
   берутся из имени файла, напр. «МЭ11 14мм 22шт.dxf»).

Версия сборки показана под заголовком программы. Если страница и сервер разных версий —
внизу вкладки «Нестинг» появится предупреждение: закройте окно программы, запустите заново и нажмите F5.
Программа сама закрывает свои прошлые экземпляры при запуске — запускать второй раз для обновления кода
достаточно, «зависших» серверов бояться не нужно.

## Готово и проверено (лично проверялось в CypCut Pro 7.1.2240.3)
- **Формат `.lxds`**: расшифрован и записывается побайтово совместимо с CypCut (контейнер, геометрия, слои).
- **Импорт DXF**: сшивка разорванных контуров, отверстия, единицы измерения, толщина/количество из имени файла.
- **Нестинг**: по реальному контуру, вложение в отверстия, повороты 90°, зоны запрета (струбцины),
  произвольные углы поворота, приоритеты деталей; гарантированный зазор между деталями.
- **Мосты** (по диагонали/у всех углов/нет) и **врезки** (линия/дуга, выбор точки на контуре) —
  видны в CypCut, контуры при этом остаются целыми.
- **Параметры резки по толщинам**: 28 режимов (Сталь 0.5–20 мм, Нержавейка 1–10, Алюминий 1–6)
  подставляются в CamParams файла `.lxds` (скорость, газ, давление, прокол); редактируются во вкладке «Режимы».
- **Гравировка артикулов**: текст DXF → контуры букв на розовом слое гравировки; шаблон артикула
  редактируется в «Настройках» (по умолчанию — из ТЗ); текст, не подходящий под шаблон, не гравируется
  и показывается в замечаниях. Для номеров вида «МЭ11», «7041» (без дефиса) задайте шаблон:
  `^[A-Za-zА-Яа-я0-9]{1,6}[-_][A-Za-zА-Яа-я0-9]{1,6}$|^[A-Za-zА-Яа-я0-9]{3,8}$`
- **Расчёт себестоимости**: формулы эталонной таблицы (сверены до 0.01 руб.); материал считается по
  реальному КИМ раскладки; кнопки «Списать листы со склада» и «Внести в расчёт» (с заменой или добавлением).
- **Виртуальный склад**: листы, остатки, списание, история, CSV-импорт, защита от минуса;
  остаток создаётся автоматически при списании.
- **Автотесты**: 154 штуки, все зелёные.

## Требует проверки на станке / у технолога
1. **Режимы Сталь 14 и 18 мм** — добавлены интерполяцией соседних (скорость попадает в диапазон таблицы
   CypCut 3 кВт, но значения надо сверить с фактом) — вкладка «Режимы».
2. **Газ N2** в CamParams: код GasType=3 не подтверждён образцами (O2 и Воздух подтверждены).
3. Мелочи формата: обязательность thumbnail.emf, флаги Curve[0]/Shape[8].

## Что осталось сделать (по приоритету)
1. **Отчёт по заказу** (ТЗ 7.7): заказ/дата/клиент/менеджер/срок, позиции, итоги, условия оплаты,
   скидки от объёма, мин. заказ; выгрузка в Excel. Образец формата: `импорт_20260929001.xlsx`.
2. **UI профилей резки** (ТЗ 8.2): оценить, чего не хватает поверх редактируемых «Режимов».
3. **Эпики** (крупные доработки, по одному заходу):
   - общий рез (common-line) соседних деталей;
   - нестинг на обрезках/нестандартных листах со склада;
   - геометрия контура остатков (сейчас остаток — прямоугольник);
   - цепочка деталей одним резом; NFP-подход для более плотной раскладки;
   - заявки на закупку листов.
4. Интерфейс ручного подтверждения «спорных» артикулов (надпись вне контура).
5. OCR по контурным текстам (PaddleOCR) — установка отдельно, в портативный пакет не входит.

## Ограничения (честно)
- Нестинг растровый: идеальное взаимопроникновение контуров недостижимо; произвольные углы дают
  уплотнение только на некоторых наборах (ограничение шага сетки 2.5 мм).
- Латунь не поддерживается форматом `.lxds`.
- Список режимов — собственный справочник (28 строк), не читается из `.fsm` CypCut (они зашифрованы).
